Distro to FTE Tool - easy deploy (Windows)

1. Unzip this folder.
2. Double-click deploy.bat and follow the 4 steps (needs Node.js and a free Vercel account).
3. Share the Production URL it prints with your co-workers.

No Node? Alternative without a terminal:
  a) Create a GitHub repo and upload these files (Add file > Upload files).
  b) On vercel.com choose Add New > Project, import that repo.
  c) Before deploying add Environment Variables: ANTHROPIC_API_KEY (required), APP_PASSWORD (optional access code).
  d) Deploy.

Without a key the page still works through Manual entry.
